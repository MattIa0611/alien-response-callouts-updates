# Alien Response Callouts updates

Public update information for **Alien Response Callouts**, by **Alien (Mattia C.)**.

The mod reads `version.txt` once when it loads. This repository contains version information only; it does not distribute the plugin or its source code.

[Download Alien Response Callouts on LCPDFR](https://www.lcpdfr.com/downloads/gta5mods/scripts/55757-alien-response-callouts/) · [Support Alien](https://ko-fi.com/alienita)

## Publishing a future update

1. Publish the tested mod package on the download page first.
2. Edit `version.txt` on the `main` branch to contain only the new version, such as `1.3` or `2.0`.
3. Commit the change. Older compatible versions with update checks enabled will show an update notification the next time they load.

Keep this repository public and keep the file path unchanged. Version numbers are compared numerically. The file must contain only a stable numeric version (2–4 components), with no additional text.

Version 1.2 is the first build with this check. Earlier builds do not check this repository. A failed/offline request never blocks the game, and the checker does not download or install updates.
